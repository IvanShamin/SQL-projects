# SQL-projects
SQL Projects
A collection of SQL and data projects built around real industrial data and structured learning.

FRITS_DB
Analysis of a ceramic frit database (1,100+ materials) used in industrial glaze production.
Covers data integrity audits, chemical profiling, cost estimation, CTE/UMF calculations, surface texture prediction, and regulatory compliance checks.
Built on a real 3-table MySQL schema from my day job.
Skills: CTEs, window functions, JOINs, aggregations, domain-specific modeling

excel-to-sql-loader
A practical workflow for loading structured Excel data into a relational database using Excel formulas, Power Query, and SQL.
Built to solve a real problem — importing 250+ raw materials from lab spreadsheets into MySQL without manual errors.
Skills: ETL design, SQL INSERT generation, Python (openpyxl), data integrity checks

sql-data-warehouse-project
Data warehouse built on Medallion Architecture (Bronze/Silver/Gold layers) using SQL Server.
Includes ETL stored procedures, data cleaning, star schema design, and quality checks.
Skills: Data engineering, ETL pipelines, stored procedures, star schema

Datacamp SQL Projects
Practice projects from DataCamp covering sales analysis, NGO impact analysis, and data formatting.
Skills: PostgreSQL, CTEs, window functions, aggregations

Karpov.courses SQL Simulator
120+ SQL tasks completed independently on the Karpov.courses platform.
Covers joins, subqueries, window functions, and analytical queries on real datasets.
